# Wi-Fi 辅助定位

## Purpose
在 GNSS 覆盖不足时使用周边 Wi-Fi 观测和定位服务估算当前位置，并明确来源、精度、时效、隐私与失败行为。

## ADDED Requirements

### Requirement: Wi-Fi 扫描与隐私
系统 SHALL 仅在运行内存中暂存有限时长的 Wi-Fi 观测数据，串口和日志不得输出接入点标识或 SSID，并提供不含标识的扫描诊断。

#### Scenario: 检查扫描
- **WHEN** 操作者请求 Wi-Fi 扫描诊断
- **THEN** 系统显示可用接入点数量和状态，但不输出接入点标识或 SSID

### Requirement: Wi-Fi 辅助定位结果
系统 SHALL 通过已授权的受认证 TLS 服务解析当前 Wi-Fi 指纹，并仅在返回合法坐标、已知坐标系、有效采集时间和未超过 60 秒的本次观测时提供估算位置；无法确认精度半径时显式标记未知，不宣称精确定位。

#### Scenario: 无服务或无结果
- **WHEN** 服务未配置、网络不可用、指纹不足或服务拒绝定位
- **THEN** 系统明确报告失败，不发布旧坐标或将 IP 位置伪装成 Wi-Fi 定位

#### Scenario: 成功定位
- **WHEN** 服务返回满足质量和时效要求的有效 Wi-Fi 定位
- **THEN** 系统提供来源为 Wi-Fi、采集时间、坐标系及明确的精度状态；无精度半径时使用 null
