# BC20 库副本

这些文件来自本机 TinkerNode NB-IoT ESP32 板包 1.0.8 的 DFRobot_NBIoT 库；官方示例标注 MIT License。项目副本只对 BC20 查询路径添加了保护：接收队列为空时不解引用空指针；整数查询无响应或格式无效时返回 255；QGNSSRD 缺失预期响应时返回失败。用途是明确区分 GNSS 电源状态未知，且不得依赖未更新的定位结构。补丁和库的其他异常路径仍需实机验证。

GSV 查询现将完整 AT 响应中的 NMEA GSV 报文交给边界检查和校验和验证的解析器，避免原有解析在异常分片时越界或除零；接收队列清空时同步清除尾指针。多信号重复报文会标为不完整。
